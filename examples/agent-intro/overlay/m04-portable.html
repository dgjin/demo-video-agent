没有任何一条路径，
写死在代码里。

# 取已安装的最新版本 DV_ROOT="${DV_HOME:-$(ls -d \ "$HOME/.qoder/plugins/cache"/*/demo-video-agent/* \ | sort -V | tail -1)}"

插件从自身安装路径推导根目录。
源码开发时用 DV_HOME 指向仓库。

01

自动定位

DV_ROOT / PLUGIN_ROOT

不管装在哪台机器、哪个版本目录，运行时自己找到自己。

02

依赖自举

auto install

安装副本不带 node_modules，缺少 playwright 时自动安装。

03

配置发现

findConfig()

从当前目录向上查找 demo-video.config.mjs，子目录里也能跑。

04

跨平台适配

macOS · Linux · Windows
